# ふたりの家計簿 公開手順

GitHub Pages(アプリの置き場所)と Firebase(データの保存先)を使って、夫婦2人だけで使える家計簿アプリを公開する手順です。どちらも無料で使えます。

## 用意するファイル

| ファイル | 役割 |
|---|---|
| `index.html` | アプリの画面 |
| `app.js` | アプリの動き(入力、集計、合言葉での共有) |
| `firebase-config.js` | Firebaseの接続設定(**ステップ4で自分の値に書き換える**) |
| `firestore.rules` | データを守るルール(**ステップ3でFirebaseに貼り付ける**) |
| `manifest.webmanifest` / `` | ホーム画面に追加したときの名前とアイコン |

---

## ステップ1:Firebaseのプロジェクトを作る

1. https://console.firebase.google.com を開き、Googleアカウントでログインします。
2. 「プロジェクトを作成」を押し、名前を入れます(例:`futari-kakeibo`)。
3. Googleアナリティクスはオフで大丈夫です。
4. 料金プランは無料の「Spark」のままで問題ありません。

## ステップ2:匿名ログインを有効にする

1. 左のメニューから「構築」→「Authentication」→「始める」を押します。
2. 「ログイン方法」タブで「匿名」を選び、「有効にする」をオンにして保存します。

> メールアドレスやパスワードは使いません。端末ごとに自動で目に見えないIDが作られ、合言葉で家計簿とつながります。

## ステップ3:データベースを作って、ルールを貼る

1. 左のメニューから「構築」→「Firestore Database」→「データベースを作成」を押します。
2. ロケーションは **`asia-northeast1`(東京)** を選びます(あとから変更できません)。
3. 「本番環境モード」で作成します。
4. 作成後、上の「ルール」タブを開き、中身をすべて消して `firestore.rules` の内容を貼り付け、「公開」を押します。

## ステップ4:接続設定を `firebase-config.js` に貼る

1. 左上の歯車 →「プロジェクトの設定」を開きます。
2. 下の「マイアプリ」で `</>`(ウェブ)のアイコンを押します。
3. アプリ名(例:`kakeibo-web`)を入れて登録します。Firebase Hostingのチェックは不要です。
4. 表示された `firebaseConfig = { ... }` の中の値を、`firebase-config.js` の「ここに貼り付け」とそれぞれ置き換えます。

```js
window.FIREBASE_CONFIG = {
  apiKey: "AIza....",
  authDomain: "futari-kakeibo.firebaseapp.com",
  projectId: "futari-kakeibo",
  storageBucket: "futari-kakeibo.appspot.com",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcdef"
};
```

> この値はアプリに埋め込む前提のもので、公開しても問題ありません。データはステップ3のルールで守られます。

## ステップ5:GitHubにアップロードする

1. https://github.com でアカウントを作ります(持っていればログイン)。
2. 右上の「+」→「New repository」を押します。
3. 名前を入れます(例:`kakeibo`)。**Public** を選んで「Create repository」を押します。
   - 無料プランでGitHub Pagesを使うにはPublicが必要です。中身はアプリのコードだけで、家計簿のデータはFirebase側にあるので見られません。
4. 「uploading an existing file」のリンクを押し、**このフォルダの中身** をドラッグ&ドロップして「Commit changes」を押します。
   - `index.html` がリポジトリの一番上の階層にある状態にしてください。

## ステップ6:GitHub Pagesで公開する

1. リポジトリの「Settings」→ 左メニュー「Pages」を開きます。
2. 「Source」を「Deploy from a branch」、Branchを `main`、フォルダを `/ (root)` にして「Save」を押します。
3. 1〜2分待つと、上に `https://ユーザー名.github.io/kakeibo/` のようなURLが表示されます。

## ステップ7:FirebaseにGitHubのアドレスを登録する

1. Firebaseの「Authentication」→「設定」タブ →「承認済みドメイン」を開きます。
2. 「ドメインの追加」で `ユーザー名.github.io` を追加します(`https://` や `/kakeibo/` は付けません)。

## ステップ8:スマホのホーム画面に追加して使う

**iPhone(Safari)**
1. ステップ6のURLをSafariで開きます。
2. 下の共有ボタン →「ホーム画面に追加」を押します。
3. **ホーム画面のアイコンから開いて**、合言葉を入れます。
   - Safariで開いた画面とホーム画面のアプリは別扱いです。合言葉はホーム画面のアプリで入れてください。

**Android(Chrome)**
1. URLを開き、右上のメニュー →「ホーム画面に追加」(または「アプリをインストール」)を押します。

## ステップ9:奥さんと共有する

1. 先に1人が合言葉を決めて「はじめる」を押し、「新しく作る」を選びます。
2. 奥さんにURLと合言葉を伝えます。奥さんもステップ8でホーム画面に追加し、同じ合言葉を入れると参加できます。
3. 開いたら「夫」「妻」のどちらかを選びます。

---

## 共有のルール

- **2人まで**:3人目は合言葉が合っていても入れません。
- **合言葉を変える**:設定 →「合言葉を変える」。データは新しい合言葉に移り、相手は締め出されます。共有をリセットしたいときに使います。
- **相手を外す**:相手が機種変更してアプリのデータが消え、入れなくなったときに使います。外したあと、相手が同じ合言葉を入れれば参加し直せます。
- **合言葉はどこにも保存されません**。忘れると、新しい端末からは開けなくなります。メモしておいてください。
- 推測されないよう、**8文字以上**で、誕生日だけなどの単純なものは避けてください。

## 注意

- 2人とも端末のアプリのデータを消す(または機種変更する)と、家計簿に入れなくなります。片方が残っていれば「相手を外す」で戻せます。
- 無料枠(1日5万回の読み込みなど)は、夫婦2人で使う分には十分です。

## 更新するとき

アプリを直したら、GitHubのリポジトリで同じ名前のファイルをアップロードし直すと、数分で反映されます。
